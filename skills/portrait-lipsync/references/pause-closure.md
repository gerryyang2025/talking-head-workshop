# 句尾闭唇与逐帧复核

## 先判断该调哪一层

用同一段配音试渲染，从最后一个字之前听到下一句起音。记下具体字、秒数、镜头和可见现象。把原始口型推理帧与最终 MP4 对到主时间轴的同一帧。逐帧比较时保留相同的脸部裁切。

| 观察到的现象 | 下一步 |
| --- | --- |
| 连续说话时，多处双唇起动都领先或落后声音 | 用前、中、后三段可见人脸交叉检查偏移。口播工坊已对 MuseTalk 输出做基线校准，先用「口型微调」0。确有一致偏差时，嘴先动试 +1 帧，嘴后动试 −1 帧，用最终成片复测。 |
| 说话同步，末音却一帧闭死，或声音已消退、嘴又张开 | 看原始推理帧是否已有跳变。已有跳变时，用下面的连续收口动作替代该停顿内不稳定的嘴型。若只在合成后出现，先查蒙版、所取帧和镜头入出点。 |
| 嘴已闭合，眨眼或头部动作却停住再跳走 | 检查句尾是否重复了同一整帧，以及下个镜头或母片循环是否提前切入。 |

## 合成一次连续的收口动作

1. **定停顿。** 对照实听、最终配音逐帧的均方根音量（RMS）和句间空隙。标出末音衰减、持续安静和下一次起音。句内的轻声、气音及短辅音保留原始发音动作。口播工坊目前在 25 fps 下用约 6 帧逐渐收口、约 4 帧逐渐松开，并允许从已经很弱且持续衰减的尾音开始。换素材、语速或帧率时按实际声音重定时长。
2. **取同镜头的三个姿势。** 取末音仍有表现力的一帧、这次停顿里自然放松的一帧，以及有下一音节时的起音帧。在安静段的起、中、末分别看一下，选与当下表情接近、双唇轻触或自然微开的候选。如果生成帧都张嘴，从同一母片的当前切片取自然闭唇的几何和纹理作参考。遇到遮挡、多人或跟踪失效，保留可信的当前画面并标出该处供复核。
3. **让唇部形状连续变化。** 以双眼和鼻部对齐头姿，将嘴角、上下唇的内外缘映射到共同的中间轮廓，平滑地从末音移向休止，再接下一音节。口腔内部取自实际露齿的一侧，唇周皮肤边缘做羽化。观察下唇和下巴是否一起放松。把整张闭嘴照淡入说话帧容易产生第二条唇线。
4. **接回镜头。** 视频母片的短句间隙，让上一句的嘴型跟着随后几帧的头姿走，接续原来的眨眼和肩颈动作。抵达切片出点时结束延续，保留原剪辑的切点。照片沿用已有底板运动。预览从停顿中间开始时，仍以主时间轴的绝对帧计算动作，只从当前镜头取图。

口播工坊的导出和剪辑预览已共用这套处理。排查实现时，从项目根目录查看 `studio/production.py` 的 `render`、`studio/mouth_rest.py` 的 `rest_weights` 和 `PausePerformance`，以及 `studio/mouth_transition.py` 的 `MovingTail`。只改停顿合成且推理输入一致时，可复用缓存的说话帧重新导出。

## 验证最终 MP4

1. 首次生成时，带声看完所有主讲句尾。在全屏人物、分屏人物和临近切镜的短停顿各留一个复查时点。从末字前播放到下句开头，看末字是否仍读得完整，唇线是否连续，停顿中是否又露齿，下一句是否自然打开。修订时，把同一时段的旧版和新版用相同裁切左右并排，以正常速度播放，共用一条配音。纯图文段跳过。
2. 逐帧量化可疑处。沿垂直于嘴角连线的方向，取三对内唇点的平均间距，再除以两嘴角距离。查看这条曲线的最大相邻帧变化、发生时间和闭后回张。检测丢失的帧留空，同一比较窗口内固定裁切并避开切镜。该指标帮助定位跳变，最终仍以带声观感判断。
3. 对照从停顿中途起播的预览和整片同一时点，检查嘴型与头姿。逐帧解码整片，核对帧数、音画时长、字幕时点。修订前后复用同一编码音轨时，可核对音频包哈希。命令见[本机案例的复查命令](musetalk-local.md#复查命令)。

### 在本机复测

从口播工坊项目根目录运行，用 `original` 和 `revised` 指向两份相同剪辑的恒定帧率 MP4。下面的例子取 25 fps 成片第 468 至 474 帧，画面左侧 691 像素为主讲区。换镜头时按实际帧号和像素调整，全屏单人可省略 `--crop`。脚本复用工作台已安装的人脸关键点模型。[逐帧测量脚本](../scripts/measure_closure.py)

```sh
PYTHONPATH=. .venv/bin/python skills/portrait-lipsync/scripts/measure_closure.py \
  "$original" "$revised" --first 468 --stop 475 --crop 0 0 691 720
```

在这次 131 秒的成片里，“看过了”的句尾（18.8 秒附近）最大单帧唇间距变化约从嘴宽的 12% 降到 4%。另一处 123.68 秒的停顿消除了可见的回张，65.4 秒处仍收得偏快。复核新片时选取它自己的台词和停顿，按正常速度回看数值变化最大的几帧。
