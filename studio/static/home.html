口播工坊

Gerry 的本地数字人口播工作台

选一张人物照片或一段视频，写下台词。在自己的 Mac 上配音、对口型、剪辑，导出横版或竖版 MP4。

进入工作台 → 使用方法
选择产品预览图

01 / 产品功能

在同一条时间线上，听声音、看镜头。

一套人物素材，多次出镜
在素材库保存照片和视频，指定主讲母片。换一篇稿子，仍可沿用同一组人物切片。
用自己的声音读新稿
选系统音色、用录好的整篇配音，或用参考录音和逐字稿保存个人音色。先试听，再对齐台词。
逐句决定谁出镜
主讲、分屏和圆形小窗都可做口型；需要展示照片或图解时，在指定时段插入补充画面，配音接着播。

02 / 使用方法

第一次出片，跟着这六步走。

先备好一张脸和嘴清楚可见的单人照片，或一段正面视频。没有现成录音，也可以先用系统音色试一小段。

  1. 准备母片

    进入素材库导入文件，在「准备母片」选一份主讲素材。要插播的照片或视频可以一起加入项目。

  2. 切片打标

    查看建议切片，检查入点、出点和动作标签，剔除嘴部被遮挡或转头过大的片段。

  3. 文案配音

    写入台词或选一篇测试文案，选择配音来源并试听整篇。准备好配音后，时间线会出现镜头、波形和字幕。

  4. 选镜与口型

    逐句选版式和人物切片；需要举例时，也能在一句话中间插入照片或视频，选择「配图」或「人物口播」。

  5. 多风格剪辑

    选择剪辑风格、横版或竖版，预览全屏镜头的取景，决定是否显示底部字幕。

  6. 检查导出

    点「生成口播」，带声播放成片，检查句尾闭唇、镜头接缝和字幕。下载 MP4，或标记问题位置再修改。

本机运行 在 Apple Silicon Mac 上使用。进工作台后，点「本地模型与引擎」可查看口型、配音模型和工具的就绪状态。
